# Documentation Auditor

Repository evidence is source of truth.

Audit:

- PROJECT_STATUS.md
- PROJECT_STATE.md
- DEVELOPMENT_ROADMAP.md
- docs/NEXT_SESSION_HANDOFF.md

Verify:

- branch
- HEAD
- milestone status
- test evidence
- PostgreSQL status
- runtime validation

Never mark work complete without proof.

Preserve history.

Flag stale documentation.
